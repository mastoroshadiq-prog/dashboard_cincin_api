Attack Rate (AR)

Bobot: 40% — Dominan

Mengapa Bobot Tertinggi?

  • ✓ Objektivitas Tertinggi: Diukur langsung dari citra satelit (NDRE), tidak bias manusia
  • ✓ Early Warning: Deteksi infeksi 3-6 bulan lebih awal dari gejala visual
  • ✓ Korelasi Penyebaran: AR >10% = fase eksponensial (doubling time <6 bulan)
  • ✓ ISO 31000 Aligned: Represents "Probability" axis in risk matrix

Scoring Tiers:

AR ≥ 10% Score: 100
AR 7-10% Score: 75
AR 5-7% Score: 50
AR < 5% Score: 0-25
💰

Financial Loss

Bobot: 30% — Impact Measure

Mengapa Bobot Kedua?

  • ✓ Impact Severity: ISO 31000 → Risk = Probability (AR) × Impact (Loss)
  • ✓ Decision Relevance: Manajemen lebih responsif terhadap angka finansial
  • ✓ Normalisasi Skala: Menyamakan blok besar & kecil berdasarkan kerugian aktual
  • ✓ Trigger CAPEX: Loss >Rp 100M = Emergency budget approval

Scoring Tiers:

≥ Rp 150 Juta Score: 100
Rp 100-150 Jt Score: 75
Rp 50-100 Jt Score: 50
< Rp 25 Jt Score: 0-25
🌴

SPH (Population Health)

Bobot: 15% — Corrective Factor

Mengapa Bukan Lebih Tinggi?

  • ✓ Corrective, Bukan Primary: SPH = konsekuensi infeksi, bukan penyebab
  • ✓ Deteksi Blind Spots: Menangkap "Cryptic Collapse" (AR rendah tapi SPH <90)< /span>
  • ✓ Ekonomi Operasional: SPH <100=biaya/ton tidak masuk akal
  • ✓ Data Limitation: Tidak semua blok punya data SPH akurat

Scoring Logic (Inverse):

SPH < 80 Score: 100 (Crisis)
SPH 80-100 Score: 75
SPH 100-120 Score: 50
SPH > 130 Score: 0 (Healthy)
📉

Yield Gap

Bobot: 15% — Temporal Validator

Mengapa Setara dengan SPH?

  • ✓ Complementary to AR: AR = spatial (infeksi aktif), Gap = temporal (trend degradasi)
  • ✓ Vanishing Yield Alert: Gap -20% = deteksi root degradation sebelum visible
  • ✓ Proxy Insolvency: Gap ≤-20% = point of no return (replanting needed)
  • ✓ Data Quality: Bergantung akurasi potensi (lebih subjektif dari AR)

Scoring Tiers (Negative Values):

Gap ≤ -20% Score: 100
Gap -15 to -20% Score: 75
Gap -10 to -15% Score: 50
Gap > -5% Score: 0
